# Post-Cleanup Notes

## Changes made

Removed the earlier notebook experiments and their sample/experiment data. `rag.ipynb` was kept.

| Removed file | What it was | Why it was safe to remove |
|---|---|---|
| `faiss.ipynb` | FAISS similarity-search experiment | Superseded by `app.py`; not imported anywhere |
| `loaders&splitters.ipynb` | Document loader / text splitter experiment | Superseded by `app.py`; not imported anywhere |
| `nvda_news_1.txt` | Sample NVIDIA article, used only by `loaders&splitters.ipynb` | Only referenced by the removed notebook |
| `sample_text.csv` | Sample records, used only by `faiss.ipynb` | Only referenced by the removed notebook |
| `vector_index.pkl` | Old experiment index | Not read by `app.py` (the API uses `faiss_index/`) or `rag.ipynb` |

Notes on the removal:
- All five files were tracked in git, so the last committed versions can be restored with `git checkout -- <file>`.
- `loaders&splitters.ipynb` had **uncommitted edits** at the time of deletion. Those edits are not recoverable.
- `generate_deck.py` still mentions `faiss.ipynb`, `loaders&splitters.ipynb`, `nvda_news_1.txt` and `sample_text.csv` as slide text. It does not load them, so it still runs. The generated `FinSight_College_Presentation.pptx` and the script's text are now slightly out of date.

## Round 2: build caches, logs and ignore rules

Removed generated clutter. Everything here is either regenerated automatically or was a one-off log.

| Removed | What it was | Why it was safe to remove |
|---|---|---|
| `api-server.log`, `api-server-error.log` | Uvicorn output from a September test run | Old run logs; not read by anything |
| `next-server.log`, `next-server-error.log` | `next dev` output from the same run | Old run logs; not read by anything |
| `__pycache__/` | Python bytecode for `app.py` | Regenerated automatically on the next run |
| `.next/` (~55 MB) | Next.js build/dev cache | Regenerated by `npm run dev` / `npm run build` |

Added a `.gitignore` covering `.venv/`, `__pycache__/`, `.ipynb_checkpoints/`, `node_modules/`, `.next/`, `*.tsbuildinfo` and `*.log`, so these stop showing up as untracked.

Deliberately kept:
- `Presentation/` (`generate_deck.py`, `FinSight_College_Presentation.pptx`, `ai_financial_bot.png`) and `rag.ipynb`, as requested.
- `node_modules/` and `.venv/`: installed dependencies needed to run the app. Now git-ignored rather than deleted.
- `faiss_index/`: the saved index that `app.py` reloads on startup.
- `next-env.d.ts`, `tsconfig.json`, `package.json`, `package-lock.json`: required by Next.js/TypeScript.
- `.vscode/settings.json`: personal editor settings (points VS Code at conda, although the project uses `.venv`). Harmless; delete it if you don't use conda.

`README.md` and `CLAUDE.md` were rewritten to match the current layout and code (item 1 below is now fixed in the README).

## Things noticed (not changed yet)

1. **README mismatch:** the README says the app talks to "ChatGPT", but `app.py` uses local Ollama `llama3` (with `nomic-embed-text` for embeddings). It also still mentions `UnstructuredURLLoader`, while the code uses `WebBaseLoader`.
2. **Index is replaced, not extended:** each "Process URLs" call builds a new FAISS index and overwrites `faiss_index/`, so earlier sources are lost.
3. **Unsafe deserialization flag:** `FAISS.load_local(..., allow_dangerous_deserialization=True)` is fine for a local index you created, but never load an index file from an untrusted source.
4. **Unused dependencies:** `requirements.txt` lists `sentence-transformers`, `pandas`, `numpy` and `tiktoken`, which neither `app.py` nor `rag.ipynb` imports. `unstructured` is only needed by `rag.ipynb` (`UnstructuredURLLoader`). Several lines also have trailing spaces.
5. ~~**Missing `.gitignore`**~~ — fixed in round 2.
6. **Deprecated FastAPI hook:** `@app.on_event("startup")` is deprecated in favour of lifespan handlers.
7. ~~**Loose prompt**~~ — the prompt now says "Answer only from the supplied context … do not invent market data".
